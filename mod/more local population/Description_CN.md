# 人矿生产中心

添加了建筑： 人矿生产中心、肉类生产中心。更新日志记录于README.

**本mod属于作弊mod，制作目的在于解除后期发展的限制。**

由于注意到小型附庸国会大规模建造本mod建筑，带来性能压力，增加了科技限制并削弱了基础生产模式性能。

人矿生产中心增加了三级生产方式，效果如下:

* 基础: 无需科技，10%出生率，每10单位工具产出一单位油、橡胶。
* 高级: 发电解锁，15%出生率，每10单位工具产出60单位油、橡胶。

* 超级: 电气化铁路解锁，20%出生率，每10单位工具产出100单位油、橡胶，30单位铁。

肉类生产中心增加了四种生产方式，效果如下:

* 基础: 无需科技，3%死亡率，每10单位工具产出10单位煤炭，油，鱼，肉。
* 高级: 黄色炸药解锁，5%死亡率，每10单位工具产出30单位煤炭，鱼，肉，60单位油，铁。
* 超级: 苯胺解锁，6%死亡率，每10单位工具产出60单位煤，铁，50单位鱼，肉，100单位油。
* 大量: 发电解锁，20%死亡率，每10单位工具产出60单位煤，铁，80单位鱼，肉，120单位油。
